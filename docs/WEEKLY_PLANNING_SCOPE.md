# 주간 계획 기능 범위 문서 (1차)

## 기능 목표

- 사용자가 기준일을 중심으로 이번 주 또는 다음 주 할 일을 한눈에 볼 수 있게 한다.
- 기존 todo의 `start_date`, `due_date`, `done`, `priority`, `role_name`을 기준으로 주간 단위로 재정리한다.
- AI가 주간 계획 후보를 제안할 수 있지만, 바로 저장하지 않고 검토 후 적용한다.

---

## 1차 구현 범위

### 주간 기준일 계산

- 주 시작 요일은 **월요일**
- `selected_date`가 속한 주의 월요일~일요일 계산
- 이번 주 보기 / 다음 주 보기 전환 지원

### 주간 todo 목록 표시

- 지연 / 이번 주 진행 / 이번 주 마감 / 다음 주 예정 정도의 간단한 그룹으로 구분
- 기존 todo 데이터만 사용
- 새 저장 구조 추가 없음

---

## 1차 제외 범위

| 항목 | 이유 |
|---|---|
| Google Calendar 연동 | 외부 API 의존, 별도 작업 |
| 반복 일정 자동 생성 | 저장 구조 변경 필요 |
| AI가 바로 todo 저장 | 검토 없는 저장 금지 원칙 |
| SQLite 전환 | 저장 계층 마이그레이션은 별도 단계 |
| 주간 리뷰 통계 고도화 | 2차 이후 |
| 드래그 앤 드롭 | Streamlit 기본 지원 미흡 |
| 복잡한 칸반 UI | 앱 복잡도 증가 방지 |

---

## UI 방향

- 전체 앱을 더 복잡하게 만들지 않는다.
- 주간 계획은 expander 또는 별도 섹션으로 시작한다.
- 기본 화면은 compact하게 유지한다.
- 오른쪽 필터 패널을 더 무겁게 만들지 않는다.
- 기존 오늘 할 일 / 전체 보기 기능과 충돌하지 않아야 한다.

---

## 주간 분류 기준

| 그룹 | 조건 |
|---|---|
| **지연** | `due_date < week_start` 이고 미완료 |
| **이번 주 진행** | `start_date <= week_end` and `due_date >= week_start` 인 미완료 |
| **이번 주 마감** | `due_date`가 `week_start~week_end` 사이인 미완료 |
| **다음 주 예정** | 다음 주 범위에 `start_date` 또는 `due_date`가 걸리는 미완료 |
| **완료 항목** | 기본 숨김, 선택 시 표시 가능 |

> 이번 주 진행과 이번 주 마감은 겹칠 수 있으므로, 표시 우선순위는 구현 시 결정한다.

---

## AI 주간 계획 후보 방향 (2차 검토)

- 기존 todo를 보고 이번 주에 집중할 후보를 제안한다.
- 새 todo를 만들 수도 있지만 반드시 미리보기/검토 후 적용한다.
- 기존 AI 자연어 파싱의 원칙을 따른다 — AI 결과를 바로 저장하지 않는다.
- 선택된 후보만 `add_todo()`를 통해 저장한다.
- **이 기능은 2차 구현으로 미룰 수 있다.**

## 수동 검증 기준

- 기준일이 수요일이면 해당 주 월요일~일요일이 정확히 계산되는지
- 월말/월초가 섞인 주도 정상 표시되는지
- 연말/연초가 섞인 주도 정상 표시되는지
- 지연 / 진행 / 마감 / 예정 분류가 의도대로 되는지
- 기존 오늘 할 일 / 전체 보기 기능이 깨지지 않는지

---

## 개발 원칙

- 작은 단위로 구현하고 검증 후 커밋한다.
- `app.py` 단일 파일 구조는 당분간 유지한다.
- 저장 계층 함수(`load_todos`, `save_todos`, `add_todo` 등)는 건드리지 않는다.
- 날짜 저장 형식은 `YYYY-MM-DD`를 유지한다.
- AI 결과는 항상 검토 후 저장한다.
