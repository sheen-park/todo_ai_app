# 백업/내보내기 기능 1차 범위 문서

## 기능 목표

- 현재 로컬 저장 파일인 `todos.json`, `roles.json`을 사용자가 안전하게 백업할 수 있게 한다.
- 백업 파일은 날짜시간이 포함된 이름으로 다운로드할 수 있게 한다.
- 향후 SQLite/Supabase 전환 전까지 JSON 기반 데이터 손실 위험을 줄인다.
- CSV 또는 Markdown 내보내기를 통해 사용자가 할 일 목록을 외부에서 확인할 수 있게 한다.

---

## 1차 구현 범위

| 항목 | 설명 |
|---|---|
| `todos.json` 백업 다운로드 | 현재 저장된 todo 전체를 JSON으로 다운로드 |
| `roles.json` 백업 다운로드 | 현재 저장된 역할 전체를 JSON으로 다운로드 |
| 통합 백업 | `todos.json` + `roles.json` JSON bundle 또는 ZIP 검토 |
| CSV 내보내기 | 전체 todo를 CSV 파일로 다운로드 |
| Markdown 내보내기 | 전체 todo를 Markdown 파일로 다운로드 |
| 파일명 timestamp | 백업 파일명에 날짜시간 포함 |

### 파일명 규칙 예시

```
todos_backup_20260514_153000.json
roles_backup_20260514_153000.json
todo_export_20260514_153000.csv
todo_export_20260514_153000.md
```

---

## 1차 제외 범위

| 제외 항목 | 이유 |
|---|---|
| 백업 파일 업로드 후 복원 기능 | 별도 브랜치에서 다룸 |
| 자동 백업 스케줄링 | 복잡도 증가, 2차 이후 검토 |
| 클라우드 백업 | 외부 서비스 의존성 증가 |
| Google Drive / Dropbox 연동 | 인증 구조 필요, 현재 범위 초과 |
| SQLite 전환 | 저장 계층 로드맵과 별도 |
| Supabase 전환 | 저장 계층 로드맵과 별도 |
| 암호화 백업 | 개인 실사용 단계에서 불필요 |

## UI 방향

- 역할/분류 관리처럼 **expander 기반**으로 시작한다.
- expander 이름: `"💾 백업/내보내기"`
- 기본은 **접힌 상태**로 둔다.
- 전체 앱을 복잡하게 만들지 않는다.
- **다운로드 버튼** 중심으로 구성한다.
- 복원 기능이 없다는 점을 UI에서 명확히 표시한다.

### 레이아웃 예시

```
💾 백업/내보내기 (접힌 상태)
├── [📥 todos.json 다운로드]
├── [📥 roles.json 다운로드]
├── [📥 CSV 내보내기]
└── [📥 Markdown 내보내기]
⚠️ 이 기능은 다운로드 전용입니다. 복원 기능은 지원하지 않습니다.
```

---

## 데이터 안전 원칙

- 다운로드 기능은 **읽기 전용**이어야 한다.
- `todos.json` / `roles.json` 원본 내용을 변경하지 않는다.
- 백업 생성 중 오류가 나도 앱이 중단되지 않아야 한다.
- 파일이 없으면 안내 메시지를 표시한다.
- `.streamlit/secrets.toml`, API key는 **절대 백업 대상에 포함하지 않는다**.
- `ignored_role_tags.json`은 현재 구조에서 사용하지 않으므로 백업 대상에 포함하지 않는다.

## CSV 내보내기 필드

| 필드 | 설명 |
|---|---|
| `id` | UUID |
| `title` | 할 일 제목 |
| `role_tag` | 역할 태그 (`@` 제외) |
| `role_name` | 역할 이름 |
| `created_date` | 생성 기준일 |
| `start_date` | 시작일 (`YYYY-MM-DD`) |
| `due_date` | 마감일 (`YYYY-MM-DD`) |
| `priority` | 우선순위 (`상`/`중`/`하`) |
| `done` | 완료 여부 (`True`/`False`) |
| `memo` | 메모 |
| `created_at` | 생성 일시 |
| `updated_at` | 수정 일시 |

## Markdown 내보내기 형식

```markdown
# Todo Export
생성: 2026-05-14 15:30:00

## 미완료 (N개)

### [역할명] 제목
- 시작일: YYYY-MM-DD
- 마감일: YYYY-MM-DD
- 우선순위: 상
- 메모: ...

## 완료 (N개)

### [역할명] 제목
- 시작일: YYYY-MM-DD
- 마감일: YYYY-MM-DD
- 우선순위: 중
```

- 미완료 항목 먼저, 완료 항목 나중에 표시
- 메모가 있으면 포함, 없으면 생략

## 수동 검증 기준

| 항목 | 확인 내용 |
|---|---|
| `todos.json` 다운로드 | 버튼 클릭 시 파일 정상 다운로드 |
| `roles.json` 다운로드 | 버튼 클릭 시 파일 정상 다운로드 |
| CSV 다운로드 | 파일 열었을 때 컬럼과 데이터 정상 |
| Markdown 다운로드 | 파일 열었을 때 형식 정상 |
| 파일명 timestamp | 다운로드 파일명에 `YYYYMMDD_HHMMSS` 포함 |
| 원본 불변 | 다운로드 후 `todos.json` / `roles.json` 내용 변경 없음 |
| 민감 정보 제외 | `secrets.toml`, API key가 다운로드 파일에 없음 |
| 파일 없을 때 | 앱이 죽지 않고 안내 메시지 표시 |

## 개발 원칙

- 작은 단위로 구현하고 검증 후 커밋한다.
- `app.py` 단일 파일 구조는 당분간 유지한다.
- 저장 계층 함수(`load_todos`, `save_todos` 등)는 변경하지 않는다.
- 다운로드 기능은 읽기 전용으로 구현한다.
- 복원 기능은 별도 브랜치에서 다룬다.
