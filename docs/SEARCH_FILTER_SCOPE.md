# 검색/필터 기능 1차 범위 문서

## 기능 목표

- 전체 todo 목록에서 원하는 할 일을 빠르게 찾는다.
- 제목, 메모, 역할/분류, 우선순위를 검색/필터 조건으로 활용한다.
- 기존 전체 보기 필터와 충돌하지 않고, 추가적인 검색어 필터로 동작한다.
- 검색은 저장 데이터를 변경하지 않는 읽기 전용 기능이다.

---

## 1차 구현 범위

| 항목 | 설명 |
|---|---|
| 검색어 입력 | 전체 보기에 검색창 추가 |
| `title` 검색 | 할 일 제목에서 검색어 포함 여부 확인 |
| `memo` 검색 | 메모에서 검색어 포함 여부 확인 |
| `@tag` 검색 | `role_tag` 필드에서 검색 |
| `role_name` 검색 | 역할 이름에서 검색 |
| 대소문자 무시 | 검색어와 필드 값을 소문자로 정규화 후 비교 |
| 공백 포함 처리 | 검색어 앞뒤 `strip()` 처리 |
| 결과 개수 표시 | 검색어가 있을 때만 `N개 결과` 표시 |
| 기존 필터와 AND 결합 | 역할 필터 + 정렬 + 완료 표시 필터와 AND 조건 |

### AND 조건 예시

```
우선순위 상 + 검색어 "보고서"  → 우선순위 상이면서 보고서 포함
분류 @sw   + 검색어 "특강"    → @sw 분류 중 특강 포함
완료 OFF   + 검색어 "발표"    → 미완료 중 발표 포함
```

## 1차 제외 범위

| 제외 항목 | 이유 |
|---|---|
| 고급 검색 문법 (`AND`, `OR`, `NOT`) | 복잡도 증가, 2차 이후 검토 |
| 정규식 검색 | 일반 사용자 대상 불필요 |
| 날짜 범위 검색 | 기존 필터로 일부 커버 |
| fuzzy search | 외부 패키지 필요 |
| 검색 히스토리 저장 | 저장 구조 변경 필요 |
| 검색 결과 하이라이트 | HTML 렌더링 복잡도 증가 |
| 전역 검색 페이지 | 별도 페이지 구조 불필요 |
| SQLite full text search | SQLite 전환 이후 검토 |

## UI 방향

- 전체 보기 **우측 필터 패널**에 검색창을 추가한다.
- 화면을 복잡하게 만들지 않는다.
- 검색창 placeholder: `"검색"`
- 검색어가 있을 때만 결과 개수를 표시한다.
- 검색 초기화 버튼은 1차에서 생략 가능하다.
- 모바일/좁은 화면에서도 깨지지 않게 한다.

### 레이아웃 예시

```
[역할 필터 ▼]  [정렬 기준 ●]  [완료 □] [완료 일괄 삭제]
[검색 ________________]
```

| 필드 | 포함 |
|---|---|
| `title` | ✅ |
| `memo` | ✅ |
| `role_tag` | ✅ |
| `role_name` | ✅ |
| `priority` | ✅ |
| `status` 표시값 | ❌ (1차 제외) |

## 검색 동작 기준

- 검색어는 `strip()` 처리한다.
- 검색어가 비어 있으면 기존 전체 보기와 동일하게 표시한다.
- 검색어가 있으면 검색 대상 필드 중 **하나라도 포함**하면 통과한다 (OR 내부 결합).
- 대소문자 구분 없이 비교한다 (`lower()`).
- `None` 값은 빈 문자열로 처리한다.
- 한글, 영문, 숫자, `@태그` 검색이 가능해야 한다.

### 동작 의사 코드

```python
def todo_matches_query(todo: dict, query: str) -> bool:
    q = query.strip().lower()
    if not q:
        return True
    fields = [
        todo.get("title") or "",
        todo.get("memo") or "",
        todo.get("role_tag") or "",
        todo.get("role_name") or "",
        todo.get("priority") or "",
    ]
    return any(q in f.lower() for f in fields)
```

## 기존 필터와의 관계

검색은 기존 필터 적용 결과에 추가로 AND 조건으로 결합한다.

```
전체 보기 데이터
  → 완료 포함/제외 필터
  → 역할 필터
  → 정렬
  → 검색어 필터 (AND)
  → 결과 표시
```

| 조합 예시 | 결과 |
|---|---|
| 완료 OFF + `"보고서"` | 미완료 보고서 포함 항목 |
| `@sw` + `"AI"` | `@sw` 분류 중 AI 포함 항목 |
| 우선순위 상 + `"강의"` | 우선순위 상이면서 강의 포함 항목 |
| 검색어 없음 | 기존 전체 보기와 동일 |

## 수동 검증 기준

| 항목 | 확인 내용 |
|---|---|
| `title` 검색 | 제목에 검색어가 포함된 항목만 표시 |
| `memo` 검색 | 메모에 검색어가 포함된 항목 표시 |
| `@tag` 검색 | `role_tag` 기준 검색 정상 |
| `role_name` 검색 | 역할 이름 기준 검색 정상 |
| 대소문자 무시 | `"AI"`, `"ai"`, `"Ai"` 결과 동일 |
| 검색어 없음 | 기존 전체 보기와 동일 결과 |
| 기존 필터와 조합 | 우선순위/역할/완료 필터와 AND 정상 동작 |
| 결과 0개 | 안내 메시지 표시, 앱 중단 없음 |
| 기능 회귀 | 오늘 할 일/주간 보기/AI 입력/직접 입력 정상 |

## 개발 원칙

- 검색은 읽기 전용이다.
- 저장 구조를 변경하지 않는다.
- AI 파싱 로직을 변경하지 않는다.
- 전체 보기의 기존 필터 기능을 깨지 않는다.
- 작은 단위로 구현하고 검증 후 커밋한다.
- `app.py` 단일 파일 구조는 당분간 유지한다.
