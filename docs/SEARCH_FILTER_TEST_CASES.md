# 검색/필터 기능 수동 회귀 테스트 기준 문서

## 문서 목적

- 전체 보기 검색 기능의 회귀 테스트 기준 문서
- 자동 테스트가 아니라 사람이 앱 화면에서 확인하는 수동 테스트 기준
- 검색 helper, 검색 UI, 기존 필터와의 조합이 정상 동작하는지 확인

---

## 검색 설계 요약

| 검색 유형 | 검색 대상 | 방식 |
|---|---|---|
| 일반 검색어 | `title`, `memo`, `priority` | 부분 포함 (AND 조건) |
| `@검색어` | `role_tag`, `role_name` | 부분 포함 / wildcard |
| `@검색어` + 일반 검색어 | 각각 위 기준 적용 | AND 조건 |

- `role_name`은 일반 검색어로 검색하지 않는다.
- `role_tag` / `role_name` 검색은 `@`가 붙은 검색어에서만 동작한다.
- `@검색어`에서는 부분 검색과 `*` / `?` wildcard를 지원한다.
- 일반 검색어에서는 wildcard를 지원하지 않는다.
- 공백으로 나뉜 검색어는 AND 조건이다.

---

## 공통 통과 기준

- 검색어가 비어 있으면 기존 전체 보기와 동일하게 표시된다.
- 일반 검색은 `title`/`memo`/`priority`만 대상으로 한다.
- `@검색`은 `role_tag`/`role_name` 대상으로만 한다.
- 일반 검색어가 `role_name`에만 있는 경우 검색 결과에 나오면 안 된다.
- `@role_name` 부분 검색이 가능해야 한다.
- `@검색`에서 `*`와 `?` wildcard가 동작해야 한다.
- 기존 완료/우선순위/상태/분류 필터와 검색은 AND 조건으로 결합되어야 한다.
- 검색 결과가 0개일 때 안내 메시지가 표시되어야 한다.
- 검색은 읽기 전용이며 저장 데이터를 변경하지 않는다.

## 테스트 케이스

### TC-01. 빈 검색어

| 항목 | 내용 |
|---|---|
| 검색어 | (없음) |
| 기대 결과 | 기존 전체 보기와 동일하게 표시 |
| 추가 확인 | 검색 결과 개수 표시 없음 |

---

### TC-02. title 검색

| 항목 | 내용 |
|---|---|
| 검색어 | `보고서` |
| 기대 결과 | `title`에 "보고서"가 포함된 항목 표시 |
| 실패 조건 | `title`/`memo`/`priority` 어디에도 없는 항목이 표시됨 |

---

### TC-03. memo 검색

| 항목 | 내용 |
|---|---|
| 조건 | `memo`에만 특정 단어가 있는 todo 준비 |
| 검색어 | 해당 memo 단어 |
| 기대 결과 | `title`에는 없어도 `memo`에 있으면 표시 |

---

### TC-04. priority 검색

| 항목 | 내용 |
|---|---|
| 검색어 | `상` |
| 기대 결과 | `priority`가 "상"인 항목 표시 |
| 주의 | `title`/`memo`에 "상"이 포함된 항목도 매칭될 수 있음 — 우선순위 필터와 혼동하지 않는다 |

---

### TC-05. role_name 일반 검색 제외

| 항목 | 내용 |
|---|---|
| 조건 | `role_name`이 "SW중심대학"인 todo 존재, `title`/`memo`/`priority`에는 없음 |
| 검색어 | `SW중심대학` |
| 기대 결과 | 해당 todo가 검색 결과에 나오지 않음 |
| 실패 조건 | `role_name`에만 있는 항목이 표시됨 |

---

### TC-06. plain tag 일반 검색 제외

| 항목 | 내용 |
|---|---|
| 조건 | `role_tag`가 "sw"인 todo 존재, `title`/`memo`/`priority`에는 "sw" 없음 |
| 검색어 | `sw` |
| 기대 결과 | `role_tag`가 sw라는 이유만으로는 표시되지 않음 |
| 참고 | `title`/`memo`에 "sw"가 있으면 표시될 수 있음 |

---

### TC-07. @role_tag 검색

| 항목 | 내용 |
|---|---|
| 검색어 | `@sw` |
| 기대 결과 | `role_tag`가 "sw"인 todo 표시 |
| 실패 조건 | `@sw` 분류가 아닌 항목이 표시됨 |

---

### TC-08. @role_name 부분 검색

| 항목 | 내용 |
|---|---|
| 조건 | `role_name`이 "하우코칭"인 todo 존재 |
| 검색어 | `@하우` |
| 기대 결과 | "하우코칭" `role_name` 항목 표시 |

| 검색어 | `@하우코칭` |
|---|---|
| 기대 결과 | 같은 항목 표시 |

---

### TC-09. @role_name 공백 제거 검색

| 항목 | 내용 |
|---|---|
| 조건 | `role_name`이 "하우코칭 강의"인 todo 존재 |
| 검색어 | `@하우코칭강의` |
| 기대 결과 | 공백이 제거된 검색어로도 해당 항목 표시 |

---

### TC-10. @검색 wildcard `*`

| 항목 | 내용 |
|---|---|
| 조건 | `role_name`이 "하우코칭"인 todo 존재 |
| 검색어 | `@하우*` |
| 기대 결과 | "하우"로 시작하는 `role_name` 또는 `role_tag` 항목 표시 |

| 검색어 | `@*코칭` |
|---|---|
| 기대 결과 | "코칭"으로 끝나는 `role_name` 항목 표시 |

---

### TC-11. @검색 wildcard `?`

| 항목 | 내용 |
|---|---|
| 조건 | `role_name`이 "하우코칭"인 todo 존재 |
| 검색어 | `@하우??` |
| 기대 결과 | "하우" 뒤 정확히 2글자 패턴에 매칭되어 표시 |
| 주의 | `?`는 정확히 1글자, full regex 아님 |

---

### TC-12. @분류 + 일반 검색 AND

| 항목 | 내용 |
|---|---|
| 검색어 | `@sw 특강` |
| 기대 결과 | `@sw` 분류이면서 `title`/`memo`/`priority`에 "특강"이 포함된 항목만 표시 |
| 실패 조건 1 | `@sw`이지만 "특강"이 없는 항목이 표시됨 |
| 실패 조건 2 | "특강"이 있지만 `@sw`가 아닌 항목이 표시됨 |

---

### TC-13. 공백 AND 검색

| 항목 | 내용 |
|---|---|
| 검색어 | `AI 특강` |
| 기대 결과 | "AI"와 "특강"이 모두 `title`/`memo`/`priority`에 포함된 항목만 표시 |
| 실패 조건 | 둘 중 하나만 포함된 항목이 표시됨 (OR처럼 동작) |

---

### TC-14. 기존 필터와 조합

**조합 1 — 우선순위 필터 + 검색어**

| 항목 | 내용 |
|---|---|
| 조건 | 우선순위 필터 "상" 선택 |
| 검색어 | `강의` |
| 기대 결과 | 우선순위 "상"이면서 "강의"가 포함된 항목만 표시 |

**조합 2 — 분류 체크박스 + 검색어**

| 항목 | 내용 |
|---|---|
| 조건 | 분류 필터 @sw만 체크 |
| 검색어 | `AI` |
| 기대 결과 | @sw 분류 중 "AI"가 포함된 항목만 표시 |

**조합 3 — 완료 포함 OFF + 검색어**

| 항목 | 내용 |
|---|---|
| 조건 | 완료 포함 OFF |
| 검색어 | `보고서` |
| 기대 결과 | 미완료 항목 중 "보고서"가 포함된 항목만 표시 |

### TC-15. 검색 결과 0개

| 항목 | 내용 |
|---|---|

---

### TC-16. wildcard 일반 검색 미지원

| 항목 | 내용 |
|---|---|
| 검색어 | `보고*` |
| 기대 결과 | wildcard로 해석하지 않음 — `title`/`memo`/`priority`에 문자 그대로 "보고*"가 없으면 매칭 안 됨 |
| 참고 | wildcard는 `@검색어`에서만 지원 |

## 실패 패턴

| 실패 패턴 | 영향 |
|---|---|
| 일반 검색어가 `role_name`에만 있는 항목을 표시함 | TC-05 실패 |
| 일반 검색어 `sw`가 `role_tag sw` 항목을 표시함 | TC-06 실패 |
| `@sw` 검색이 `role_tag sw` 항목을 찾지 못함 | TC-07 실패 |
| `@하우` 검색이 `role_name 하우코칭`을 찾지 못함 | TC-08 실패 |
| `@하우*` wildcard가 동작하지 않음 | TC-10 실패 |
| 일반 검색에서 wildcard가 동작함 | TC-16 실패 |
| `@sw 특강`이 OR처럼 동작해 하나만 있어도 표시됨 | TC-12 실패 |
| 기존 우선순위/상태/분류 필터와 검색이 AND로 결합되지 않음 | TC-14 실패 |
| 검색 결과 0개에서 안내가 없거나 traceback 발생 | TC-15 실패 |
| 검색 실행 후 저장 데이터가 변경됨 | 데이터 무결성 위반 |

---

## 개발 원칙

- 검색은 읽기 전용이다.
- 일반 검색은 `title`/`memo`/`priority` 중심으로 유지한다.
- 분류 검색은 `@검색어`로만 수행한다.
- full regex는 지원하지 않는다.
- wildcard는 `@검색어`에만 제한한다.
- 검색 기능은 전체 보기의 기존 필터와 충돌하지 않아야 한다.
