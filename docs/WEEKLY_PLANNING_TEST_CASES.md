# 주간 보기 기능 수동 회귀 테스트 케이스

## 목적

주간 보기 기능을 수정할 때마다 날짜 계산, 이번 주/다음 주 분류, 진행률, 날짜 표시가 깨지지 않았는지 수동으로 확인하기 위한 기준 문서다.  
자동 테스트가 아니라 사람이 앱 화면에서 직접 확인하는 수동 테스트 기준이다.  
주간 보기 수정 전후에 반드시 이 문서의 항목들을 확인한다.

---

## 공통 통과 기준

- 주 시작은 **월요일**
- `selected_date` 기준 이번 주 월요일~일요일이 정확히 표시되어야 함
- 다음 주는 이번 주 시작일 + 7일 기준으로 계산되어야 함
- 조회 화면의 날짜 표시는 `M/D(요일)` 형식이어야 함
- 내부 저장값은 `YYYY-MM-DD` 형식을 유지해야 함
- 이번 주 보기에는 지난주 미완료 지연 항목이 포함되어야 함
- 다음 주 보기에는 지연 항목이 포함되지 않아야 함
- 주간 보기 목록은 한 줄 compact 표시를 유지해야 함
- 주간 보기에서 완료 상태 변경, 저장, AI 생성은 하지 않음

---

## 실패 패턴

| 패턴 | 설명 |
|---|---|
| 이번 주가 월요일 시작이 아님 | `weekday()` 계산 오류 |
| 다음 주 범위가 +7일이 아님 | `get_next_week_range()` 오류 |
| 이번 주 보기에서 지난주 미완료가 빠짐 | `due < week_start` 조건 누락 |
| 다음 주 보기에 지연 항목이 섞임 | `due < next_start` 필터 누락 |
| 완료 todo가 진행률에 반영되지 않음 | `weekly_total` 계산 오류 |
| 주간 보기 항목이 두 줄 이상으로 길어짐 | 두 번째 줄 정보 렌더링 |
| 날짜가 `YYYY-MM-DD`로 표시됨 | `format_date_kr_short()` 미적용 |
| 주간 보기에서 저장/수정/완료 변경 발생 | 저장 함수 호출 오류 |
| 우선순위 아이콘이 상태 아이콘과 혼동됨 | 색상 원형 아이콘 재사용 금지 |

## 테스트 케이스

### TC-01 기준 주 계산

**기준일**: `2026-05-13`

**기대**
- 이번 주: `5/11(월) ~ 5/17(일)`
- 다음 주: `5/18(월) ~ 5/24(일)`

**통과 기준**
- 주간 보기 expander 열었을 때 위 범위가 caption에 정확히 표시됨

---

### TC-02 월말/월초 경계

**기준일**: `2026-06-01` (월요일)

**기대**
- 이번 주: `6/1(월) ~ 6/7(일)`
- 다음 주: `6/8(월) ~ 6/14(일)`

**기준일**: `2026-05-31` (일요일)

**기대**
- 이번 주: `5/25(월) ~ 5/31(일)`
- 다음 주: `6/1(월) ~ 6/7(일)` — 5월 말과 6월 초를 자연스럽게 포함

**통과 기준**
- 월 경계가 생겨도 날짜 표시와 분류가 정상 동작함

---

### TC-03 연말/연초 경계

**기준일**: `2026-12-31` (목요일)

**기대**
- 이번 주: `12/28(월) ~ 1/3(일)` — 2026년 말과 2027년 초를 포함
- 날짜 표시가 깨지지 않아야 함

**통과 기준**
- `format_date_kr_short()` 변환이 연도 경계에서 정상 동작함

---

### TC-04 이번 주 보기 — 지난주 미완료 포함

**조건**
- `due_date`가 이번 주 시작일보다 이전인 todo
- `done = False`

**기대**
- 이번 주 보기 실행 목록에 표시됨
- 다음 주 보기에는 표시되지 않음

**통과 기준**
- 지난주 미완료 todo가 이번 주 실행 목록에 포함됨 (`get_current_week_items` 검증)

---

### TC-05 이번 주 보기 — 기간 겹침

**조건**
- `start_date <= week_end` and `due_date >= week_start`
- `done = False`

**기대**
- 이번 주 실행 목록에 표시됨

**통과 기준**
- `date_ranges_overlap()` 정상 동작 확인

---

### TC-06 이번 주 진행률

**조건**
- 이번 주 대상 todo 전체 7개
- 그중 완료 4개 (`done = True`, 날짜 범위 이번 주와 겹침)

**기대**
- **진행률 4/7** 형식으로 표시됨
- 완료 todo는 실행 목록에는 보이지 않지만 진행률 분자에는 반영됨

**통과 기준**
- `weekly_total = 7`, `weekly_active = 3`, `done_count = 4`

---

### TC-07 이번 주 모두 완료

**조건**
- 이번 주 대상 todo가 모두 `done = True`

**기대**
- 실행 목록은 비어 있음
- "이번 주 할 일을 모두 완료했습니다. 🎉" 또는 이에 준하는 메시지 표시

**통과 기준**
- `weekly_active` 길이 0일 때 빈 목록 없이 완료 메시지만 표시됨

---

### TC-08 다음 주 보기

**조건**
- 다음 주 기간과 겹치는 미완료 todo
- 이번 주까지만 `due_date`인 지연 todo (`due < next_start`)

**기대**
- 다음 주 기간 todo만 표시됨
- 지연 todo는 표시되지 않음
- "다음 주 진행 예정 N개" 형식으로 개수 표시

**통과 기준**
- `get_next_week_items()`의 `due < next_start` 필터 검증

---

### TC-09 한 줄 compact 표시

**기대 표시 형식**
```
- 교내 창업경진대회 모집 공고 및 접수 양식 준비 @sw · 5/20(수) ‼️
- 제주도 가족여행 교통·숙소 확인 @family · 5/23(토) ❗
- 법인카드 증빙자료 수합 및 제출 · 5/16(금)
```

**통과 기준**
- 각 항목이 한 줄로 표시됨
- 두 번째 줄에 기간/분류/역할 정보가 표시되지 않음
- `title · M/D(요일) 우선순위아이콘 메모아이콘` 순서

---

### TC-10 우선순위 아이콘

**기대**

| 우선순위 | 주간 보기 아이콘 |
|---|---|
| 상 | ‼️ |
| 중 | ❗ |
| 하 | (없음) |

**통과 기준**
- 오늘 할 일/전체 보기의 🔴🟢🔵 상태 아이콘과 혼동되지 않음
- 하 우선순위 항목에 아이콘이 표시되지 않음

---

### TC-11 메모 표시

**조건**: `memo`가 있는 todo

**기대**
- 주간 보기에서 memo 본문을 표시하지 않음
- memo가 있는 경우 📝 아이콘만 title 뒤에 표시
- 목록이 길어지지 않아야 함

**통과 기준**
- 메모 있는 항목: `title · M/D(요일) ‼️ 📝`
- 메모 내용이 목록에 출력되지 않음

---

### TC-12 날짜 저장 형식 회귀

**조건**: 주간 보기 확인 후 `todos.json` 내용 점검

**기대**
- `todos.json`의 `start_date`, `due_date`는 `YYYY-MM-DD` 형식 유지
- 화면 표시만 `M/D(요일)` 형식

**통과 기준**
- `todos.json` 열었을 때 날짜 필드가 `"2026-05-17"` 형태로 유지됨

---

### TC-13 기존 기능 회귀

주간 보기 추가 이후 다음 기존 기능들이 정상 동작하는지 확인한다.

| 기능 | 확인 항목 |
|---|---|
| 오늘 할 일 | 기준일 기준 todo 정상 표시 |
| 전체 보기 | 필터/정렬/상세/수정/삭제 정상 |
| AI 자연어 입력 | 파싱 후보 정상 표시 및 적용 |
| 직접 입력 | 저장 후 목록에 즉시 반영 |
| 완료 체크 | 체크 후 상태 변경 및 재렌더 정상 |
| 수정/삭제 | 전체 보기에서 수정·삭제 정상 |

---

## 개발 원칙

- 주간 보기는 **빠른 확인용 실행 목록**이다.
- 상세 확인은 전체 보기에서 한다.
- 주간 보기에서 직접 수정 기능을 넣지 않는다.
- Google Calendar 연동 전까지는 기존 todo 데이터만 사용한다.
- 추후 Calendar가 붙으면 주간 보기에서 일정을 보며 todo 입력하는 방향으로 확장한다.
